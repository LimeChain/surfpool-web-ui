## What is Surfpool?

Surfpool is a drop-in replacement for `solana-test-validator` that fetches accounts just-in-time from Mainnet. No manual cloning. No stale state. Your transactions get exactly what they need, when they need it.

```bash
curl -sL https://run.surfpool.run | bash
surfpool
```

That's it. You now have a local Solana environment with access to every account on Mainnet.

## What's in 1.0

### Mainnet Forking

When you send a transaction to Surfpool, it analyzes which accounts are needed. If an account doesn't exist locally, Surfpool fetches it from Mainnet before executing.

- **Test against real program state** without cloning programs manually
- **Interact with any token** using actual mint metadata
- **Simulate swaps** with real liquidity pool data
- **Debug production issues** by replaying transactions locally

### Cheatcodes

Real-world testing requires more than mainnet data. You need to manipulate state, control time, and simulate edge cases.

**Time travel:**
```typescript
await surfpool.warp({ slots: 1000 });
```

**Set balances:**
```typescript
await surfpool.airdrop({
  address: wallet.publicKey,
  lamports: 100 * LAMPORTS_PER_SOL
});
```

**Modify accounts:**
```typescript
await surfpool.setAccount({
  address: configAccount,
  data: Buffer.from([/* your test data */]),
  owner: programId,
});
```

**Profile compute units:**
```typescript
const profile = await surfpool.cuProfile({ transaction: tx });
// { total: 45_230, breakdown: [...] }
```

### New TUI
