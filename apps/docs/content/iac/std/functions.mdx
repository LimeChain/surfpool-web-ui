---
title: Standard Functions
description: Utility functions available in the standard library
---

These functions are available in all Runbooks as part of the standard library.

## Operators

Basic mathematical and comparison operators:

```hcl
// Addition
output "sum" {
    value = 1 + 2  // or add_uint(1, 2)
}

// Subtraction
output "diff" {
    value = 5 - 3  // or sub_uint(5, 3)
}

// Multiplication
output "product" {
    value = 4 * 3  // or mul_uint(4, 3)
}

// Division
output "quotient" {
    value = 10 / 2  // or div_uint(10, 2)
}
```

## Hash Functions

```hcl
// SHA256 hash
output "hash" {
    value = std::sha256("hello world")
}

// Keccak256 hash
output "keccak" {
    value = std::keccak256("hello world")
}
```

## Hex Functions

```hcl
// Encode to hex
output "hex" {
    value = std::encode_hex("hello")
}

// Decode from hex
output "decoded" {
    value = std::decode_hex("68656c6c6f")
}
```

## Base64 Functions

```hcl
// Encode to base64
output "base64" {
    value = std::encode_base64("hello world")
}

// Decode from base64
output "decoded" {
    value = std::decode_base64("aGVsbG8gd29ybGQ=")
}
```

## JSON Functions

```hcl
// Encode to JSON
output "json" {
    value = std::encode_json({ "key": "value" })
}

// Decode from JSON
output "decoded" {
    value = std::decode_json("{\"key\": \"value\"}")
}
```

## List Functions

```hcl
// Get list length
output "length" {
    value = std::len([1, 2, 3, 4, 5])
}

// Get element at index
output "element" {
    value = std::element([1, 2, 3], 1)  // Returns 2
}
```

## Assertion Functions

```hcl
// Assert equality
variable "check" {
    value = std::assert_eq(1, 1)  // Returns true
}

// Assert not equal
variable "check2" {
    value = std::assert_ne(1, 2)  // Returns true
}
```
