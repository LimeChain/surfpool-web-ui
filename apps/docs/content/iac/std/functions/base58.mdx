## encode_base58

`encode_base58` encodes a hex string as a base58 string.

### Inputs

| Name | Type | Description |
|------|------|-------------|
| `hex_string` | string | The hex string to encode |

### Output

| Name | Type | Description |
|------|------|-------------|
| `value` | string | The base58-encoded string |

```hcl
output "encoded_base58" {
    value = encode_base58(0x68656c6c6f)
}
// > encoded_base58: Cn8eVZg
```
